# Exam Panic — Local AI Study Planner

Exam Panic is a local AI study planner powered by Tether's QVAC SDK.

It helps students create practical exam study plans from their subjects, available study time, and preparation level.

## ✨ Features

- 🤖 AI-generated study plans
- 🔒 Runs AI inference locally on the device
- 📚 Subject and topic-based planning
- ⏱️ Time-based study scheduling
- 🧠 Revision and practice-question planning
- 🚫 No external AI API key required

## 🛠️ Tech Stack

- Node.js
- Express.js
- Tether QVAC SDK
- HTML
- CSS
- JavaScript

## 📦 QVAC SDK

This project uses:

`@qvac/sdk`

The QVAC model is loaded and executed locally using QVAC's on-device inference.
